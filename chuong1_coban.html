1. Biến (Variable) và Các Kiểu Dữ Liệu

Trong Scratch, em phải bấm nút "Tạo một biến". Trong Python, em chỉ cần đặt tên và dùng dấu = để cất giá trị vào chiếc hộp đó!

Kiểu dữ liệu Tên trong Python Ví dụ Ghi chú giới hạn
Số nguyên int tuoi = 8 Không giới hạn độ lớn (tính chính xác tới hàng trăm chữ số!)
Số thập phân float chieu_cao = 1.35 Dùng dấu chấm . thay cho dấu phẩy
Chuỗi ký tự str ten = "Minh" Đặt trong dấu nháy kép " " hoặc nháy đơn ' '
Đúng / Sai bool cham_chi = True Viết hoa chữ cái đầu: True hoặc False

2. Các Phép Tính Toán & Thứ Tự Ưu Tiên

a = 10
b = 3
print(a + b)   # Cộng: 13
print(a - b)   # Trừ: 7
print(a * b)   # Nhân: 30
print(a / b)   # Chia lấy số thập phân: 3.3333333333333335
print(a // b)  # Chia lấy phần nguyên: 3
print(a % b)   # Chia lấy số dư: 1
print(a ** b)  # Lũy thừa (10 mũ 3): 1000
Thứ tự ưu tiên phép tính: Giống hệt toán học ở trường: Trong ngoặc ( ) → Lũy thừa ** → Nhân/Chia * / // % → Cộng/Trừ + -.
Ví dụ: Muốn tính trung bình có hệ số, bắt buộc phải đóng ngoặc tử số: (toan * 2 + van * 2 + anh) / 5.

3. Ứng Dụng // và % Để Quy Đổi & Tách Chữ Số

Hai phép toán chia lấy nguyên (//) và chia lấy dư (%) cực kỳ hữu ích trong lập trình:

# 1. Quy đổi thời gian từ tổng số giây S (ví dụ S = 3661):
gio = S // 3600           # 1 giờ (vì 1 giờ = 3600 giây)
phut = (S % 3600) // 60   # Lấy số giây lẻ sau khi chia giờ, rồi chia 60 -> 1 phút
giay = S % 60             # Số giây còn dư lại -> 1 giây

# 2. Tách từng chữ số của một số có 4 chữ số (ví dụ N = 1234):
hang_nghin = N // 1000          # 1
hang_tram  = (N // 100) % 10    # 2
hang_chuc  = (N // 10) % 10     # 3
hang_donvi = N % 10             # 4

4. Ép Kiểu Dữ Liệu (Type Casting)

Chuỗi "5" là chữ cái, không thể cộng trực tiếp với số 10. Ta cần biến đổi kiểu dữ liệu cho chúng:

chu_so = "5"
so_nguyen = int(chu_so)      # Biến "5" thành số 5
so_thuc = float("1.5")       # Biến "1.5" thành số 1.5
chuoi_moi = str(100)         # Biến số 100 thành chuỗi "100"

5. Mật Mã Chữ Cái (Bảng Mã ASCII)

Mỗi ký tự đều có một "số báo danh" riêng gọi là mã ASCII ('A' là 65, 'B' là 66, 'a' là 97).

print(ord('A'))            # Xem mã ASCII của 'A' -> 65
print(chr(66))             # Từ mã 66 tìm lại ký tự -> B
print(chr(ord('A') + 1))   # Tìm chữ cái liền sau 'A' -> B
