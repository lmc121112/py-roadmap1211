1. Biến (Variable) và Các Kiểu Dữ Liệu

Trong Scratch, em phải bấm nút "Tạo một biến". Trong Python, em chỉ cần đặt tên và dùng dấu = để cất giá trị vào chiếc hộp đó!

Kiểu dữ liệu Tên trong Python Ví dụ Ghi chú giới hạn
Số nguyên int tuoi = 8 Không giới hạn độ lớn (lưu được cả số có hàng trăm chữ số!)
Số thập phân float chieu_cao = 1.35 Dùng dấu chấm . thay cho dấu phẩy
Chuỗi ký tự str ten = "Minh" Phải đặt trong dấu nháy kép " " hoặc nháy đơn ' '
Đúng / Sai bool cham_chi = True Viết hoa chữ cái đầu: True hoặc False

2. Các Phép Tính Toán Trong Python

a = 10
b = 3
print(a + b)   # Cộng: 13
print(a - b)   # Trừ: 7
print(a * b)   # Nhân: 30
print(a / b)   # Chia lấy số thập phân: 3.3333333333333335
print(a // b)  # Chia lấy phần nguyên: 3
print(a % b)   # Chia lấy số dư: 1
print(a ** b)  # Lũy thừa (10 mũ 3): 1000
Mẹo nhớ: Khác với toán học thông thường, phép chia / luôn ra số thập phân. Muốn lấy kết quả nguyên như phép chia có dư ở lớp 3, hãy dùng // và %.

3. Ép Kiểu Dữ Liệu (Type Casting)

Chuỗi "5" là chữ cái, không thể cộng trực tiếp với số 10. Ta cần biến đổi kiểu dữ liệu cho chúng:

chu_so = "5"
so_nguyen = int(chu_so)      # Biến "5" thành số 5
so_thuc = float("1.5")       # Biến "1.5" thành số 1.5
chuoi_moi = str(100)         # Biến số 100 thành chuỗi "100"

4. Mật Mã Chữ Cái (Bảng Mã ASCII)

Máy tính không hiểu chữ cái, nó chỉ hiểu các con số! Mỗi chữ cái đều có một "số báo danh" riêng gọi là mã ASCII (ví dụ: 'A' là 65, 'B' là 66, 'a' là 97).

# Hàm ord(): Xem số báo danh của 1 ký tự
print(ord('A'))       # Kết quả: 65

# Hàm chr(): Từ số báo danh tìm lại ký tự
print(chr(66))       # Kết quả: B

# Tìm chữ cái đứng liền sau 'A':
ma_tiep_theo = ord('A') + 1
print(chr(ma_tiep_theo))  # Kết quả: B
